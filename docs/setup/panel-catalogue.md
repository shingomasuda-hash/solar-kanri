# パネルカタログの登録 / Panel catalogue

デモ用データから実データへ移行するための手順書。

---

## 1. デモを起動する

```bash
npm run db:seed:demo
```

パネル10件、損失係数9件、電力単価1件、日射量観測点4件を投入し、係数セットと単価を
デモ用のものに切り替えます。これで**住所検索 → 屋根作図 → パネル配置 → 発電量 →
経済効果 → 見積作成**まで通して動きます。

**投入される値はすべて概算です。** 出典はなく、どのメーカーの公表仕様でもありません。
システムは次のように扱います。

|                      | 挙動                                       |
| -------------------- | ------------------------------------------ |
| シミュレーション実行 | できる（デモの目的そのもの）               |
| 画面表示             | すべて「参考値（デモ用データ）」の警告つき |
| 見積の下書き         | できる                                     |
| **見積の発行**       | **拒否される**（`DemoQuotationError`）     |
| 印刷／PDF            | 用紙上部に警告帯が印字される               |

概算値は「だいたい合っている」ため、欠損値より危険です。だから発行だけは通しません。

---

## 2. 実データに差し替える

デモ行は上書きされません。管理画面から実データを新規登録し、デモ行を無効化してください。

### 2-1. パネル（管理 → パネル）

データシート1枚につき、以下の項目を転記します。**推測で埋めないでください。**
数値が読み取れない項目は空欄のまま登録できます（`温度係数` を除く）。

| 画面の項目           | データシートの表記               | 単位・注意                                    |
| -------------------- | -------------------------------- | --------------------------------------------- |
| メーカー / 型番      | 型式・品番                       | 版数（改訂記号）も `データシート版数` に記録  |
| 公称最大出力         | Pmax / 公称最大出力              | W。STC の値                                   |
| 外形寸法             | 寸法（縦×横×厚さ）               | **mm**。縦横の取り違えは配置枚数に直結します  |
| 質量                 | 質量                             | kg。屋根荷重の確認用                          |
| モジュール変換効率   | モジュール変換効率               | %                                             |
| **温度係数（Pmax）** | 温度係数 Pmax / γ                | **必須**。`-0.35 %/℃` は `-0.0035` として保存 |
| NOCT / NMOT          | NOCT または NMOT                 | ℃                                             |
| 年間出力低下率       | 出力保証の年劣化率               | `0.5 %/年` は `0.005`                         |
| 保証年数             | 製品保証 / 出力保証              | 年                                            |
| 出典                 | データシートのタイトルと発行年月 | URLも入力                                     |

温度係数の単位取り違え（%/℃ をそのまま入れる）は **100倍の誤り**になります。
サーバー側で範囲検査していますが、入力時にも確認してください。

登録後、内容をデータシートと突き合わせて「確認済み」にすると、そのパネルは
`MANUFACTURER_DATASHEET` として扱われ、見積発行の対象になります。

### 2-2. 国内住宅用の主要メーカー

デモに入れた10件と同じ並びです。**下の「主なシリーズ」は調査の出発点であって、
型番でも仕様でもありません。** 必ずメーカーの公式データシートを取得してください。

| #   | メーカー               | 主なシリーズ（要確認）            | 備考                                 |
| --- | ---------------------- | --------------------------------- | ------------------------------------ |
| 1   | 長州産業               | Gシリーズ / Bシリーズ             | 台形モジュールがあり、寄棟屋根で有利 |
| 2   | ハンファQセルズ        | Q.PEAK 系 / N型バックコンタクト系 | 新築市場で採用が多い                 |
| 3   | カナディアンソーラー   | HiKu 系                           | 同上                                 |
| 4   | シャープ               | BLACKSOLAR 系                     | 国内シェア上位                       |
| 5   | パナソニック           | 住宅用モジュール                  |                                      |
| 6   | 京セラ                 | 住宅用モジュール                  | 小型モジュールがある                 |
| 7   | ネクストエナジー       | 住宅用モジュール                  |                                      |
| 8   | トリナソーラー         | Vertex 系                         |                                      |
| 9   | エクソル               | XLN 系                            |                                      |
| 10  | マキシオン（SunPower） | 高効率モジュール                  | 高効率帯                             |

出発点として使える公開比較記事:
[ソーラーパートナーズ](https://www.solar-partners.jp/contents/171.html) ·
[EV DAYS（東京電力EP）](https://evdays.tepco.co.jp/entry/2022/12/07/kurashi32)

これらは**記事であって一次資料ではありません**。掲載値をそのまま登録しないでください。

### 2-3. 損失係数（管理 → 係数）

| キー                    | 何の値か             | 出典として妥当なもの                            |
| ----------------------- | -------------------- | ----------------------------------------------- |
| `inverterEfficiency`    | パワコン効率         | パワコンのデータシート（定格effまたは加重効率） |
| `wiringFactor`          | 配線損失             | JIS C 8907、または自社の設計基準                |
| `soilingFactor`         | 汚れ損失             | JIS C 8907、JPEA 表示ガイドライン               |
| `shadingFactor`         | 影損失               | 現地調査、または自社基準                        |
| `otherApprovedFactor`   | その他損失           | 同上                                            |
| `temperatureRiseK.*`    | 設置形態別の温度上昇 | JIS C 8907 の設置区分                           |
| `gridCo2FactorKgPerKWh` | 系統CO2排出係数      | 該当電力会社の公表排出係数（年度を明記）        |

### 2-4. 電力単価（管理 → 単価）

売電単価・買電単価・利益率は**経営判断**です。公開値をそのまま既定にせず、
自社の方針として承認したうえで登録してください。

| 項目                 | 参照先                                     |
| -------------------- | ------------------------------------------ |
| 売電単価（FIT/FIP）  | 資源エネルギー庁の当年度の調達価格         |
| 買電単価             | 対象顧客の契約プラン、または自社の標準想定 |
| 買取期間・期間後単価 | 同上                                       |

### 2-5. 日射量（管理 → 日射量）

デモの観測点4件は概算です。実運用では NEDO METPV / MONSOLA などの公的データセット、
または PVGIS を使ってください（`SOLAR_PROVIDER_ORDER` で優先順を設定）。

---

## 3. デモを終了する

1. 実データを登録し、それぞれ「確認済み」にする
2. 管理 → 係数 / 単価 で、実データ側のセットを**既定**に切り替える
3. 管理 → パネル でデモ行を無効化する
4. 管理 → システム状態 が緑になっていることを確認する

デモ行が既定でなくなった時点で、新しいシミュレーションには `参考値` が付かなくなり、
見積を発行できるようになります。**すでに発行済みの見積は書き換わりません** —
発行時点の入力スナップショットで固定されているためです。
